# TFT Analyzer

TFT Analyzer is a full-stack Teamfight Tactics analytics project that uses the Riot Games API to collect and analyze player match data. The goal of the project is to turn raw match information into useful player statistics and insights.

The project currently includes player search, match history analysis, player statistics, trait and unit data, and MongoDB data storage. The backend is built with Node.js, Express, and Mongoose. The frontend uses HTML, CSS, and JavaScript.

The project is also being designed with future AI and machine learning integration in mind, with the goal of eventually using player data and analytics to generate personalized gameplay insights.

### Technologies

* JavaScript
* Node.js
* Express
* MongoDB
* Mongoose
* Riot Games API
* HTML/CSS
* AI/ML (planned)
